
-"GET" : cumple la función de leer u obtener elementos de el diccionario
-"POST": crea un nuevo elemento en el diccionario, cada recurso se asocia con una nueva clave
-"DELETE": elimina un elemento del diccionario
-"PATCH": modifica parcialmente un elemento existente en el diccionario

idempotencia: "POST" no es idempotente ya que cada elemento creado se vincula con una clave diferente dentro de el diccionario
